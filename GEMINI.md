# scqo-qm — agent instructions

Two documents. Pick by **where you are working**, because several of their rules are
opposites:

- **In a fork, or contributing back?** Read [AGENTS.md](AGENTS.md) — the contributor
  brief. Work on a feature branch, open a pull request.
- **In the maintainer's lab tree?** Read [CLAUDE.md](CLAUDE.md) — lab operations.
  That checkout is shared and live: `main` stays checked out and commits go in by
  explicit pathspec.

If you are unsure, you are in a fork: read AGENTS.md.

> These files are not transcluded — open and read the one that applies.
